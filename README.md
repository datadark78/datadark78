## 🔧 En qué trabajo

La mayor parte de este trabajo vive en repositorios privados (contienen datos internos), pero esto es lo que hago:

### 📈 Automatización de Zabbix
Scripts en Python y PowerShell sobre la API de Zabbix para administrar hosts en volumen.
- **Stack:** Python, PowerShell, Zabbix API
- **Qué hace:** alta masiva de hosts y cámaras desde CSV/Excel, etiquetado con un esquema de tags unificado (`entorno`, `servicio`, `sede`, `os`), detección y limpieza de duplicados, unificación de grupos, auditorías de cobertura e informes
- **Práctica:** tokens por variable de entorno, respaldo previo a cada cambio masivo y log para poder revertir

### 📊 Grafana
- Dashboards de cámaras y servidores sobre datos de Zabbix
- Scripts para unificar dashboards, cambiar grupos y analizar dependencias

### 🌐 NetErnest – gestión de ONUs en OLT ZTE
Herramienta de escritorio para consultar y gestionar ONUs en redes GPON.
- **Stack:** Python, Netmiko, CustomTkinter, PyInstaller
- **Características:** estado de PON y ONU, inventario sin interfaz gráfica, backups, monitor de Rogue ONU, tests con fixtures de salidas de OLT

### 🖥️ Dashboard de monitoreo
Aplicación web para ver el estado de equipos Windows en tiempo real.
- **Stack:** Flask, WinRM, ICMP, HTTPS
- **Características:** credenciales cifradas (keyring), notificaciones de escritorio

### 🚀 Despliegue del agente Zabbix
- **Stack:** Ansible, PowerShell, GitHub Actions, GitLab CI
- **Qué hace:** instalación y actualización del agente en Windows y Linux, con secretos gestionados por el CI
